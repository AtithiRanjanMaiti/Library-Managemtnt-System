# Library-Managemtnt-System
A console-based Library Management System developed using Java, Object-Oriented Programming (OOP), and File Handling.

## Features
- Add new books
- View all books
- Search books by title
- Issue books
- Return books
- Store records in file for data persistence

## Technologies Used
- Java
- OOP Concepts (Inheritance, Encapsulation)
- File Handling
- ArrayList

## Project Structure
- `LibraryItem.java` → Base class
- `Book.java` → Book details and issue/return functionality
- `Library.java` → Library operations and file management
- `Main.java` → Main menu and user interaction
